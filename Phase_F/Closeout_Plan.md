## 1. 退役條件

喺以下任何一種情況下，任務將進入退役程序：

| # | 條件 | 說明 |
|:---|:---|:---|
| 1 | **設計壽命屆滿** | 營運滿 15 年 |
| 2 | **災難性故障** | 核心子系統無法修復 |
| 3 | **成本效益過低** | 年營運成本 > 年發電收入 |

## 2. 關閉程序

### 2.1 關閉順序

| 步驟 | 動作 | 說明 |
|:---|:---|:---|
| 1 | 停止雷射傳輸 | 通知地球接收站 |
| 2 | 關閉太陽能系統 | 斷開電路，太陽能板傾斜減少反射 |
| 3 | 切換至備用電源 | 維持控制系統 48 小時 |
| 4 | 下載最後數據 | 傳回地球存檔 |
| 5 | 關閉 EDS 系統 | 最後一次除塵 |
| 6 | 關閉冷卻系統 | 排空冷卻液 |
| 7 | 關閉控制系統 | 發送最後通訊 |
| 8 | 切斷所有電源 | 平台靜止 |

### 2.2 預計關閉時間

| 階段 | 時間 | 備註 |
|:---|:---|:---|
| 準備工作 | 1 週 | 通知、備份 |
| 關閉操作 | 24 小時 | 自動化執行 |
| 最終確認 | 48 小時 | 遠程檢查 |

## 5. 設備處置

### 5.1 處置選項

| 選項 | 說明 | 可行性 |
|:---|:---|:---|
| 1. 留原地 | 平台靜止，不處理 | ✅ 最簡單 |
| 2. 部分回收 | 回收有價值組件 | ⚠️ 成本高 |
| 3. 作為紀念碑 | 保留作為月球南極地標 | ✅ 有意義 |
| 4. 拆解回收 | 機械人拆解，材料再利用 | ⚠️ 技術複雜 |

### 5.2 推薦方案

**平台留原地，關閉後作為月球南極「人類能源先驅」紀念碑。**

| 優點 | 缺點 |
|:---|:---|
| 無需額外成本 | 留下太空垃圾 |
| 無技術風險 | - |
| 具歷史意義 | - |
| 可作未來參考 | - |
