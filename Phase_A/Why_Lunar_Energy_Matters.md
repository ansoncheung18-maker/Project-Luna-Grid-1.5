# 為什麼月球能源對人類文明至關重要？

**Project Luna-Grid 1.5 嘅真正價值，唔止係「賣電」。**

## 一、直接經濟價值

### 1.1 為地球提供清潔能源

| 參數 | 數值 |
|:---|:---|
| 年發電量 | 7,624 億度電 |
| 可供應家庭 | ~2.2 億戶 |
| 減排效果 | 相當於減少 4 億噸 CO₂/年 |
| 回本期 | 77 天（保守工業電價） |

**意義**：月球能源可以成為地球清潔能源嘅重要組成部分，補足太陽能、風能嘅不穩定性。

### 1.2 經濟效益

| 對比項 | 月球能源 | 地球太陽能 | 核能 |
|:---|:---|:---|:---|
| 每千瓦成本 | ~$160 美元 | ~$1,000 美元 | ~$5,000 美元 |
| 24/7 供電 | ✅ 是 | ❌ 否 | ✅ 是 |
| 燃料依賴 | 無 | 無 | 需鈾燃料 |
| 安全風險 | 極低 | 低 | 中等 |

**意義**：月球能源係目前已知最平嘅「基載電力」方案之一。

## 二、戰略價值

### 2.1 支援月球基地（NASA Artemis 計劃）

| 需求 | 月球能源可以點幫？ |
|:---|:---|
| 月球基地生活用電 | ✅ 直接供應 |
| 製氧、製水 | ✅ 供電支持 ISRU |
| 月球車充電 | ✅ 建立充電網絡 |
| 科學儀器運作 | ✅ 24/7 供電 |

**意義**：冇穩定能源，月球基地就只係「短暫停留」；有能源，先可以「永久居住」。

### 2.2 地球戰略備援

| 情境 | 月球能源嘅作用 |
|:---|:---|
| 地球大規模停電 | 透過微波/雷射緊急供電 |
| 自然災害 | 不受地球天氣影響 |
| 戰爭/能源封鎖 | 能源來源不受地緣政治限制 |

**意義**：月球能源係地球嘅「能源保險」。
