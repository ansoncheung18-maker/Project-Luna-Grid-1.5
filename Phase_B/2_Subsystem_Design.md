# 月球專案 Phase B：子系統設計（Subsystem Design）

**版本：1.0**  
**更新日期：2026-05-29**

## 1. 太陽能子系統

### 1.1 設計目標
- 提供 870 GW 平均功率
- 適應月球南極低角度日照（1.5-1.8°）
- 抵抗輻射、月塵、極端溫差

### 1.2 技術方案

| 組件 | 規格 | 說明 |
|:---|:---|:---|
| 電池類型 | GaAs/鈣鈦礦四接面 | 實驗室效率 48% |
| 安裝方式 | 垂直掛載於 50 米塔 | 正對地平線入射光 |
| 保護層 | 50 μm 石英玻璃 | 抗輻射、抗月塵 |
| 防塵 | 靜電防塵膜（EDS） | 清潔頻率 205 天 |

### 1.3 質量與功率

| 參數 | 數值 |
|:---|:---|
| 總面積 | 50 km² |
| 面密度 | 0.15 kg/m² |
| 總質量 | 7,500 噸 |
| 效率 | 48% |
| 總發電量 | 870 GW |

## 2. 結構子系統

### 2.1 設計目標
- 支撐 50 km² 太陽能板
- 抵禦月球震動、溫差應力
- 使用 ISRU 減少地球運送質量

### 2.2 技術方案

| 組件 | 規格 | 說明 |
|:---|:---|:---|
| 塔類型 | 3D 垂直光柵 | 高 50 米，寬 10 米 |
| 塔材料 | 月壤燒結 + 碳纖維 | 月球本地製造 |
| 塔數量 | 128,000 座 | |
| 連接方式 | 榫卯式接合 + 燒結固化 | 無需金屬螺絲 |

### 2.3 質量

| 參數 | 數值 |
|:---|:---|
| 每座質量 | 50 kg（優化後） |
| 總質量 | 6,400 噸 |
| 地球運送 | 0 噸（ISRU） |

## 3. 儲能子系統

### 3.1 設計目標
- 應對月球南極 3-5 天夜間
- 平滑功率輸出
- 應對突發峰值需求

### 3.2 技術方案（優化後）

| 組件 | 規格 | 說明 |
|:---|:---|:---|
| 主儲能 | 飛輪儲能 | 高效率、長壽命 |
| 備用儲能 | 鋰電池 | 緊急備用 |
| 總容量 | 5 GWh | 應對 3 天夜間 |
| 與月球基地共享 | 使用基地備用電源 | 減少獨立儲能 |

### 3.3 質量（優化後）

| 參數 | 數值 |
|:---|:---|
| 飛輪質量 | 1,000 噸 |
| 鋰電池質量 | 1,000 噸 |
| 總質量 | 2,000 噸 |

### 4.1 設計目標
- 將 852 GW 功率傳送至地球
- 效率 >85%
- 避免大氣干擾

### 4.2 技術方案

| 參數 | 規格 | 說明 |
|:---|:---|:---|
| 主方案 | 1064 nm 雷射 + AO | 效率 85% |
| 備用方案 | 2.45 GHz 微波 | 效率 60% |
| 發射器數量 | 1,000 個 | 相控陣 |
| 接收站直徑 | 380 米 | 地球高海拔沙漠 |

### 4.3 質量

| 參數 | 數值 |
|:---|:---|
| 雷射發射器 | 500 噸 |
| 自適應光學（AO） | 300 噸 |
| 備用微波天線 | 200 噸 |
| 總質量 | 1,000 噸 |

## 7. 子系統整合

### 7.1 子系統關係（文字描述）

**能量流向：**
- 太陽能子系統（870 GW）→ 儲能子系統（平滑輸出）→ 傳輸子系統（852 GW）→ 地球接收站

**質量流向（地球運送）：**
- 太陽能（7,500噸）+ 儲能（2,000噸）+ 傳輸（1,000噸）+ 控制（100噸）+ ISRU（500噸）= 11,100噸

**月球本地製造：**
- ISRU 子系統（500噸）→ 結構子系統（6,400噸，0噸地球運送）

### 7.2 子系統依賴關係

| 子系統 | 依賴 | 被依賴 |
|:---|:---|:---|
| 太陽能 | 結構、控制 | 儲能、傳輸 |
| 結構 | ISRU | 太陽能 |
| 儲能 | 太陽能、控制 | 傳輸 |
| 傳輸 | 儲能、控制 | 地球接收站 |
| 控制 | 太陽能 | 所有子系統 |
| ISRU | 控制 | 結構 |
